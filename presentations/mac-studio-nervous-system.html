Transformer vs Mamba

TransformerMamba (SSM)
MemoryGrows with context (KV cache)Fixed size — constant
SpeedSlows on long sequencesLinear scaling, 5-7x faster
QualityBest for deep reasoning~4% better at same size, weaker on recall
Always-onExpensive to keep runningDesigned for continuous inference
Fine-tuningExpensive (quadratic)Linear cost — nightly LoRA feasible
Best forThinking hardSensing continuously

Mamba-3 released March 17, 2026 — designed for inference, not training. Open source.

09

Voice — Qwen3-TTS

3-second voice cloning. Real voice. Local. No cloud.

Current: Piper TTS

  • Amy voice (en_US-amy-medium)
  • Functional but flat (~7/10 quality)
  • No voice cloning capability
  • CPU-viable but robotic

Mac Studio: Qwen3-TTS

  • 0.6B model — real-time on M4 Max (RTF ~1.0)
  • 3-second voice cloning from audio sample
  • Rich, expressive, multilingual
  • OpenAI-compatible API — zero code changes

The Plan

  • Generate reference clip of Eusha's ideal voice (ElevenLabs or curated sample)
  • Clone it locally with Qwen3-TTS — runs on Mac Studio forever, no API costs
  • Drop-in replacement: point OpenClaw TTS baseUrl to local Qwen3-TTS server
  • Piper stays as CPU fallback if Mac Studio is busy
