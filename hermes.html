Architecture Overview

Orpheus TTS is a Llama-3.2-3B fine-tune that emits SNAC audio tokens directly.

EPUB → chapter text → annotated JSON segments → Orpheus TTS → WAV chunks → MP3/M4B → Audiobookshelf
  • Text → llama-server (Metal, :1234) → SNAC token stream → snac_24khz decoder (MPS) → 24 kHz PCM WAV
  • 7 SNAC tokens per audio frame
  • Prompt format: <|audio|>{voice}: {text}<|eot_id|>
  • Speed: ~1.6× realtime on Mac Studio M4 Max

- speaker — character name or "narrator"
- text — the chunk text

For each annotated segment, synthesize audio via Orpheus.

|------------|---------|

| paragraph_end | 300 ms |
| thought_complete | 300 ms |
| scene_break | 800 ms |
