FIRST: Hit Ctrl+C in Terminal to clear the stuck dquote prompt.

Then paste each block one at a time.

mkdir -p /Users/eusha/.ssh

Step 2: Set permissions on directory

chmod 700 /Users/eusha/.ssh

Step 3: Write the key file

printf 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIL/3Fdn5gneJdWBRZOSwdzQyw/U48quSsKX6nV493CPx\n' > /Users/eusha/.ssh/authorized_keys

Step 4: Set permissions on key file

chmod 600 /Users/eusha/.ssh/authorized_keys

cat /Users/eusha/.ssh/authorized_keys
