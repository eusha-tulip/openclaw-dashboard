⏳ 1. Disable Sleep (requires sudo password)

sudo pmset -a disablesleep 1 && sudo pmset -a sleep 0

Prevents the Mac from sleeping. Essential for a server that needs to stay up 24/7.

⏳ 2. Verify Sleep Settings

pmset -g

Look for "sleep 0" and "disablesleep 1" in the output.

⏳ 3. Set Gateway Remote URL (if using ngrok/tailscale)

Replace YOUR_REMOTE_URL with the ngrok/tailscale URL. This lets Telegram reach the gateway.
